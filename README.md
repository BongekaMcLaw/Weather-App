# Weather App

A weather dashboard that lets users search any city and see current conditions plus a 5-day forecast. 

## Features
- Search for current weather by city name.
- Handles loading and error states (e.g., if a city is not found).
- Responsive, glassmorphism UI.

## Tech Stack
- HTML5
- CSS3 (Flexbox, gradients, backdrop-filter)
- Vanilla JavaScript (Fetch API, Async/Await)
- OpenWeatherMap API

## What I Learned
Building this taught me how to handle asynchronous API calls, manage UI states (loading/error/success), and safely encode user input into a URL.
